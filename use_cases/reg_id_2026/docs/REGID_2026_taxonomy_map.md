# Registration ID / BulkID run — taxonomy consolidation

How the 101 raw labels in `reg_id_manually tagged.xlsx` `[raw data tagged]` map onto the 34 cleaned categories used by `regid_taxonomy`.

Backbone: the `Distinct` tab, minus 4 rows that are notes rather than categories. Additions: the categories carrying real volume in the raw labels that the `Distinct` tab has no home for.

Generated by `notebooks/16_reg_id_2026_bulkid_taxonomy.ipynb`. Do not edit by hand.
